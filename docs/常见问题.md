# 常见问题（FAQ）

面向使用 Offer 捕手的同学。按现象查找即可。

---

## 注册与邮件

### 注册后没收到邮件？

1. 查看 **垃圾箱**、**订阅邮件**、QQ 邮箱的 **「其他」** 文件夹。  
2. 确认邮箱地址填写正确。  
3. 等待 1～3 分钟后再试；高峰时可能延迟。  
4. 使用注册页的 **重发验证邮件**，或 **忘记密码** 再发一封。  
5. 若仍无邮件，可能是站点 **未配置发信**（管理员问题），请联系提供网站的一方。

### 邮件里的链接打不开？

1. 尽量用 **Chrome / Edge / Safari** 打开，不要只在 QQ 内置浏览器里点（部分环境会拦截）。  
2. 将链接 **完整复制** 到浏览器地址栏打开。  
3. 链接一般 **24 小时内有效**；过期请重发邮件。  
4. 确认链接里的网址与管理员提供的访问地址一致（不要用别人电脑上的 `localhost` 链接）。

### 提示「该邮箱已注册」？

- 已验证过：请直接 **登录** 或 **忘记密码**。  
- 注册过但未设密码：用 **忘记密码** 重发「设置密码」邮件，不要重复注册。

### 登录提示「邮箱尚未验证」？

请先完成邮件中的 **设置密码** 步骤；或在登录页尝试 **重发验证邮件**。

## 登录与密码

### 忘记密码怎么办？

登录页 → **忘记密码** → 收邮件 → 打开链接设置新密码。

### 密码有什么要求？

一般为 **至少 6 位**；建议使用字母+数字组合，且不要与其他网站相同。

### 登录提示「邮箱或密码错误」？

- 检查大小写、是否用了注册时的邮箱。  
- 若刚设密，请确认已完成邮件中的设密页面。  
- 多次失败可能被临时限制，请 **稍后再试**（约 15 分钟）。

## 功能使用

### AI 功能提示要配置 API Key？

在左侧边栏找到 **DeepSeek API Key**，填入你在 [DeepSeek 平台](https://platform.deepseek.com/) 申请的密钥并保存。  
没有密钥则 **AI 查找、对话、部分分析** 无法使用；浏览岗位库、上传简历等不依赖 Key 的功能仍可使用（视站点配置而定）。

### 上传简历失败？

- 确认格式为 **PDF、DOCX 或 TXT**。  
- 文件不宜过大（通常 10MB 以内）。  
- 扫描版 PDF 识别率可能较低，可尝试可复制文字的 PDF 或 Word。

### 岗位匹配 / 分析很慢？

AI 分析需要调用大模型，**几十秒到一两分钟** 属正常，请勿重复点击。网络不佳时会更慢。

### 点了「结合简历分析」没有结果？

1. 确认已在侧栏 **上传简历**（并设为当前简历）。  
2. 确认已配置有效的 **DeepSeek API Key**。  
3. 在 **岗位库** 列表中先 **选中一条岗位**，再点击「结合简历分析」；结果在 **右侧详情区** 展示，不是在「心仪岗位」标签页才显示。  
4. 分析进行中请等待，勿重复点击。

### 为什么我看不到别人录入的岗位？

默认 **各账号岗位互不互通**：只有 **系统示例岗位**、**你自己添加的**、以及他人 **已点击「共享给其他用户」** 的岗位会出现在你的列表中。若需要协作，请让对方在岗位详情里开启共享。

### 如何把自己的岗位给别人看？

打开 **岗位库** → 选中你的岗位 → 在详情区点击 **「共享给其他用户」**。取消共享后，他人列表中将不再显示（你本人仍可见）。

### 如何删除已上传的简历？

在 **对话** 页左侧边栏的简历列表中，点击对应简历旁的删除操作。删除当前简历后，系统会自动选用最新上传的一份作为当前简历。

### 对话没有回复或报错？

1. 确认已配置有效的 **API Key**。  
2. 检查 Key 是否过期、余额是否充足。  
3. 稍后重试；若持续失败，联系管理员。

## 访问网站

### 页面打不开？

- 确认网址是否正确（含 **http/https** 和端口，例如 `:8080`）。  
- 换网络或换浏览器试一次。  
- 校园网/公司网可能拦截部分端口，可换手机 **4G/5G** 试。  
- 服务器或安全组问题需由 **管理员** 处理，用户无法自行修复。

### 手机和电脑表现不一致？

优先在 **系统浏览器** 中打开完整链接；避免仅用微信/QQ 内置浏览器打开复杂页面。

## 账号与安全

### 可以多人共用一个账号吗？

不建议。API Key 与简历、对话记录都绑定在个人账号上，共用存在隐私与费用风险。

### 如何保护我的 API Key？

- 不要将 Key 发给他人或写在公开场合。  
- 若怀疑泄露，到 DeepSeek 控制台 **作废并重新创建**，再在网站侧边栏更新保存。

## 服务器部署（Ubuntu）

### `permission denied` 连接 docker.sock？

当前 Linux 用户默认不能操作 Docker。在服务器上执行：

```bash
sudo docker compose -p offer-hunter up -d --build
```

或把用户加入 docker 组后 **重新登录 SSH**：`sudo usermod -aG docker $USER`。详见 [DEPLOY.md](../DEPLOY.md)。

### `version` is obsolete 警告？

可忽略，或 `git pull` 最新代码（已移除 `docker-compose.yml` 顶层 `version` 字段）。
