# Offer 捕手 — 使用指南

面向**使用者**的说明：如何注册、登录，以及如何使用岗位匹配、简历分析等功能。  
若你是开发者或运维，请看 [技术文档索引](./README.md) 与 [服务器部署](../DEPLOY.md)。

---

## 这是什么？

**Offer 捕手** 是面向学生的求职助手，帮你：

- 管理简历，并从 PDF / Word / 文本中自动提取信息  
- 收藏、录入或通过 AI 发现心仪岗位  
- 对比简历与岗位，获得匹配分析与优化建议  
- 在对话界面用自然语言咨询求职问题（需配置 AI 能力）

---

## 开始之前

- 使用 **Chrome、Edge、Safari** 等现代浏览器（手机也可用浏览器打开）。  
- 注册时需要能收到邮件（用于设置登录密码）。  
- 使用 **AI 查找岗位、对话、深度分析** 等功能前，需在侧边栏配置 **DeepSeek API Key**（见下文「配置 AI 密钥」）。未配置时，部分功能可能不可用。

---

## 注册与登录

### 注册新账号

1. 打开网站，点击 **注册**。  
2. 填写 **邮箱** 和 **昵称**（注册页无需填写密码）。  
3. 提交后，系统会向你的邮箱发送 **「设置密码」** 链接。  
4. 打开邮件中的链接，在页面中 **设置密码并完成验证**。  
5. 返回 **登录**，用邮箱和新密码登录。

**说明：**

- 一个邮箱只能注册一个账号。  
- 若提示「该邮箱已注册但未完成验证」，请使用 **忘记密码** 重发设置密码邮件。  
- 邮件可能在 **垃圾箱**，请一并查看。

### 登录

- 使用注册邮箱和密码登录。  
- 若提示「邮箱尚未验证」，请先完成邮件中的设密步骤，或在登录页使用 **重发验证邮件**（如有）。

### 忘记密码

1. 在登录页进入 **忘记密码**。  
2. 输入注册邮箱，查收邮件。  
3. 点击邮件中的链接 **设置新密码**。  
4. 使用新密码登录。

## 界面概览

登录后默认进入 **对话** 主界面。顶部或导航可进入：

| 入口 | 作用 |
|------|------|
| **对话**（首页） | 与 AI 交流求职问题；侧边栏管理会话与简历 |
| **岗位库** | 浏览、录入、AI 搜岗、心仪岗位分析 |
| **岗位库匹配** | 根据简历与求职意向，从岗位库中智能推荐 |
| **求职意向** | 填写目标城市、岗位方向、行业、实习/校招等 |

左侧 **侧边栏**（可收起）常用功能：

- **上传简历**：支持 PDF、DOCX、TXT  
- **简历列表**：切换当前用于匹配的简历版本  
- **配置 API Key**：填写你自己的 DeepSeek 密钥（见下）

---

## 推荐使用顺序

1. **登录**  
2. 在侧边栏 **上传简历**  
3. 打开 **求职意向**，填写城市、岗位、行业  
4. 进入 **岗位库**：  
   - 浏览已有岗位；或  
   - 使用 **心仪岗位** 粘贴招聘文案 / 上传截图；或  
   - 使用 **AI 查找** 搜索并导入岗位  
5. 对心仪岗位可 **结合简历分析**；或在 **岗位库匹配** 中批量推荐  
6. 在 **对话** 中提问，例如：「根据我的简历推荐适合的实习岗位」

## 各功能说明

### 求职意向

填写你关心的 **城市、岗位名称、行业**，并选择 **实习** 或 **校招**。保存后，**岗位库匹配** 会参考这些信息。

### 简历

- 支持 **PDF、Word（.docx）、纯文本**。  
- 新上传的简历通常会设为 **当前简历**；可在侧边栏切换到历史版本。  
- 简历内容仅用于为你提供分析，请确保信息真实。

### 岗位库

- **浏览**：按城市、类型等筛选岗位。  
- **手动录入**：自行添加公司、职位、要求等。  
- **心仪岗位**：粘贴 BOSS直聘、智联等页面的职位描述，或上传截图，系统自动解析。  
- **AI 查找**：用自然语言描述你想找的岗位，由 AI 搜索并导入（需 API Key）。  
- **结合简历分析**：针对某一岗位，生成匹配度、优势、不足与建议。

### 岗位库匹配

在岗位库基础上，根据 **当前简历 + 求职意向** 生成推荐列表与匹配报告，适合「不知道从哪投起」时使用。

### 对话

- 输入问题即可获得回复；支持 **Markdown** 展示。  
- 可新建多个会话，在侧边栏切换。  
- 复杂问题可能需要数十秒，请耐心等待。

### 配置 AI 密钥

1. 打开左侧边栏底部的 **API Key** 区域。  
2. 在 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并创建 API Key（以 `sk-` 开头）。  
3. 粘贴到输入框并 **保存**。  
4. 密钥保存在你的账号下，仅用于调用 AI，请勿泄露给他人。

若站点由管理员统一配置了服务器密钥，你可能无需自行填写（以实际界面提示为准）。

## 隐私与诚信提示

- 请如实填写简历与求职信息；AI 建议仅供参考，不能替代你的判断。  
- 不要与他人共享账号密码或 API Key。  
- 上传到系统的简历与对话内容，请遵守学校与用人单位的相关规定。
